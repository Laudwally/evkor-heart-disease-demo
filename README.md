# Evkor Heart Disease Classification Demo

Educational portfolio project using the UCI Cleveland Heart Disease dataset.

This is **not a medical device** and must not be used for diagnosis, screening, triage, or treatment decisions.

## Running it

Open `Evkor_Heart_Disease_Demo.ipynb` in Jupyter or Google Colab and run all cells. The notebook downloads the dataset, trains a model, and produces evaluation plots (ROC, precision-recall, calibration, confusion matrix, permutation importance).
